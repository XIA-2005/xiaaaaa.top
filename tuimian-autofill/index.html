已经安装过旧版本？这样升级不会丢个人档案

最重要的两点：先导出 JSON 备份；不要在浏览器里删除旧扩展，也不要直接加载另一个位置的新 dist 文件夹。

个人档案保存在浏览器的 chrome.storage.local 中，并与扩展 ID 绑定。对“加载已解压扩展”的用户来说，继续使用原来的文件夹路径，才能让扩展 ID 保持不变并自动读取原档案。

  1. 先备份：打开旧版扩展 →“打开档案编辑器”→ 点击“导出 JSON 备份”，保存好 tuimian-profile.json。
  2. 保留旧扩展：打开 edge://extensions 或 chrome://extensions，不要点击“删除”。确认旧版当前加载的是哪个 dist 文件夹。
  3. 解压新版：下载 v2.0.1 安装包并完整解压，在临时位置找到新版的 dist 文件夹。
  4. 原目录覆盖：把新版 dist 里面的全部文件和子文件夹复制到旧版正在使用的那个 dist 目录中，选择“替换目标中的文件”。不要复制成 旧 dist\dist 的双层目录。
  5. 刷新扩展：回到扩展管理页，在“预推免填表助手”卡片上点击“重新加载/刷新”按钮；然后刷新已经打开的报名网页。
  6. 检查完成：确认扩展管理页显示版本 2.0.1，再打开档案编辑器检查原有资料。若从 v1.x 升级，旧档案会自动迁移到 V2；请检查待分类内容并确认迁移，旧版四表备份仍会保留。
如果升级后看到空档案：先不要继续填写或删除旧文件。若你误删了旧扩展、换了目录或换了电脑，扩展 ID 可能已经改变；打开新版档案编辑器，点击“导入 JSON”，选择第 1 步导出的 tuimian-profile.json，确认内容无误后保存即可恢复。

安装教程

1. 下载并解压

  1. 点击上方“下载安装包”。
  2. 将 ZIP 完整解压到一个不会经常移动的位置。
  3. 解压后确认其中存在 dist 文件夹。

2. Edge 浏览器

  1. 在地址栏打开 edge://extensions。
  2. 打开页面左侧的“开发人员模式”。
  3. 点击“加载解压缩的扩展”，选择刚才解压出的 dist 文件夹。
  4. 在工具栏扩展菜单中固定“预推免填表助手”。

3. Chrome 浏览器

  1. 在地址栏打开 chrome://extensions。
  2. 打开右上角“开发者模式”。
  3. 点击“加载已解压的扩展程序”，选择 dist 文件夹。
首次安装可直接按以上步骤操作；已经装过旧版本的用户，请严格按照上方“原目录覆盖”方法升级，避免扩展 ID 改变后看不到原档案。

使用方法

  1. 点击扩展图标，打开档案编辑器并录入个人材料。
  2. 人工登录目标学校报名系统，并人工完成验证码或短信验证。
  3. 进入报名表页面，点击右侧悬浮面板中的“一键填充”。
  4. 检查红色、黄色提示项，人工补全并核对。
  5. 确认所有内容正确后，由你本人点击网站的提交按钮。
扩展不会自动提交报名表。绿色代表已填，红色代表需要人工处理，黄色代表档案中没有对应内容。

隐私与安全

  • 个人档案保存于浏览器本地 chrome.storage.local。
  • 不会读取或填写密码、验证码、短信验证字段。
  • 不会上传个人档案；网页也没有接入第三方访客跟踪代码。
  • 安装包由本站直接提供，可使用页首 SHA-256 校验文件完整性。

常见问题

扩展面板没有出现？

浏览器内置页面（如 edge://）不允许扩展注入内容。请在普通网页中点击扩展图标，再选择“在当前页显示悬浮面板”。

部分字段没有自动填写？

先检查档案中是否有对应内容。下拉框选项与档案不一致时，工具会保守跳过并标红，请人工选择。

如何反馈不支持的学校页面？

使用悬浮面板的“复制字段报告”功能，然后到 GitHub Issues 提交。字段报告不包含已填写的个人信息。
